SJ CRANES SERVICES WEBSITE

Files:
- index.html: website structure and content
- style.css: responsive styling and layout
- script.js: mobile navigation menu

Preview:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet connection is required for Google Fonts and the remote crane/construction photos.

Publish with GitHub Pages:
1. Upload index.html, style.css, script.js and README.txt to your GitHub repository root.
2. Open repository Settings > Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose main branch and /(root), then Save.
5. Wait for GitHub Pages to provide the public website URL.

Before publishing, replace the sample phone number and email address in index.html with your correct business contact details. Replace any stock photos with your own crane fleet and project photos for the best result.
